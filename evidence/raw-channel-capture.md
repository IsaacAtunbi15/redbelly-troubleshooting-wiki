## Note on "Building on redbelly.network is permissionless"

Appie (Redbelly team), 5 Aug 2026 12:51.

This appears to contradict wiki entry [D1], which states that an address needs a network
access credential before it can write to the chain. Both can be true at once — "permissionless"
in the sense that no approval is required to *launch a project*, while individual accounts
still self-enable write access through the access dApp. Redbelly's own user-access page is
explicit on the latter:

> "each user must claim their access credential from a network accredited issuer before they
> self enable their account with write access to the network through a specific network smart
> contract"

The message was also made in the context of a debate about whether Tokeniser crowds out other
builders, not about account permissioning, so it is probably answering a different question.

**This is not resolved by argument.** Harness checks `D1.1` (un-onboarded address probe) and
`D1.3` (onboarded address probe) settle it empirically. If an un-onboarded address turns out
to transact fine on testnet, entry D1 gets rewritten to match. This is also on the list of
questions to put to the Discord.
